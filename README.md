# Fortimber — Adapta Native

Repositório de trabalho do projeto Fortimber. O diretório atual de entrega é [Fase 2](04_fase-atual/fase.md); as especificações executáveis estão em [04_fase-atual/specs](04_fase-atual/specs/), e o escopo geral está em [01_projeto/02-Escopo-Definitivo.md](01_projeto/02-Escopo-Definitivo.md).

## Como navegar

- `01_projeto/` — objetivo e escopo aprovado/compartilhado do projeto.
- `02_reunioes/` — atas liberadas para o projeto. Não inclui gravações nem transcrições brutas.
- `03_documentos/` — documentos operacionais liberados.
- `04_fase-atual/` — tarefas e SPECs da fase em execução.
- Sistema: [Fortimber/fortimber-zzniaopq4](https://github.com/Fortimber/fortimber-zzniaopq4) (PocketBase via Skip).
- `05_entregas/` — entregas concluídas e evidências liberadas (Fase 1 arquivada em `05_entregas/fase-1/`).
- `06_notas/` — notas de trabalho compartilháveis.
- `STATUS.md` e `changelog.md` — estado e histórico das entregas deste repositório.

Antes de implementar uma tarefa, leia a SPEC correspondente, feche as decisões bloqueadoras com os responsáveis da Fortimber e registre as evidências de aceite. Não coloque credenciais, dados pessoais ou arquivos de produção neste repositório.
